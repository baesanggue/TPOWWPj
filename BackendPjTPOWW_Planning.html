1. 프로젝트 개요

1.1. 기획의도

"오늘 뭐 입지?"

매일 아침, 날씨와 상황(TPO: Time, Place, Occasion)을 고려하여 옷을 고르는 것은 많은 사람들에게 고민거리입니다. 단순히 기온만 알려주는 기존 날씨 앱과는 달리, TPOWWPj는 사용자의 성별, 나이, 선호 스타일(브랜드, 색상) 과 구체적인 상황(데이트, 운동, 출근 등) 을 고려하여, 현재 날씨에 최적화된 복장을 AI가 추천해주는 서비스를 목표로 합니다.

Google Gemini AI를 활용하여 단순한 규칙 기반 추천을 넘어, 실제 코디네이터가 조언해주는 듯한 구체적이고 자연스러운 추천 결과를 제공합니다.

1.2. 벤치마킹

  • 네이버 날씨: 실시간 날씨 정보 및 시간대별 예보 UI를 벤치마킹하여, 사용자에게 익숙하고 직관적인 날씨 정보를 제공합니다.
  • AI 챗봇 서비스: 자연어 기반의 추천 방식을 참고하여, 딱딱한 데이터 나열이 아닌 대화형 추천 텍스트를 생성합니다.

3. 주요 기능

3.1. 회원 관리 (Member Management)

  • 회원가입: 아이디, 비밀번호, 이름, 나이, 성별뿐만 아니라 거주 지역(시/도, 시/군/구) 을 입력받아 날씨 조회에 활용합니다.
  • 로그인/로그아웃: 세션 기반의 인증 시스템을 구축하여 보안을 유지합니다.
  • 마이페이지: 내 정보 수정 및 선호 스타일(브랜드, 색상, 퍼스널컬러) 을 설정하여 AI 추천의 정확도를 높입니다.

3.2. 날씨 정보 제공 (Weather Service)

  • 기상청 API 연동: 공공데이터포털의 기상청 단기예보 및 중기예보 API를 연동합니다.
  • 위치 기반 날씨: 회원의 거주지(region, sigungu) 정보를 좌표(LocationCoord)로 변환하여 해당 지역의 정확한 날씨를 제공합니다.
  • 단기/중기 예보:
    • 오늘/내일/모레: 단기예보(시간대별 기온, 습도) 활용
    • 3일 이후: 중기예보(오전/오후 날씨, 기온) 활용

3.3. AI TPO 코디 추천 (AI Recommendation)

  • Gemini Pro 연동: Google의 생성형 AI 모델인 Gemini Pro를 활용합니다.
  • 프롬프트 엔지니어링:
    • Input: 날씨 데이터(기온, 습도, 날씨상태) + 사용자 정보(성별, 나이) + 선호도(브랜드, 색상) + TPO(시간, 장소, 상황)
    • Process: 위 정보를 조합하여 최적의 코디를 제안하는 프롬프트 생성
    • Output: 상의, 하의, 아우터, 신발 등 구체적인 아이템 추천 및 스타일링 팁 제공
  • 히스토리 저장: 추천 받은 내역을 DB에 저장하여 나중에 다시 확인할 수 있습니다.

3.4. 관리자 기능 (Admin)

  • 회원 관리: 전체 회원 목록 조회 및 강제 탈퇴, 권한 수정 기능을 제공합니다.
  • 관리자 보호: 관리자 본인 삭제 방지 등 안전장치를 마련했습니다.

5. 개발 환경 및 기술 스택

  • OS: Windows 10/11
  • Language: Java 17, HTML5, CSS3, JavaScript
  • Server: Apache Tomcat 9.0
  • Database: MySQL 8.0
  • Library: JSTL, Gson (JSON Parsing), JDBC
  • API: Google Gemini API, 기상청 단기/중기예보 API
  • Tool: Eclipse IDE, DBeaver, Postman

6. 기대 효과

  • 외출 전 옷차림 고민 시간 단축
  • 날씨와 상황에 맞지 않는 옷차림으로 인한 불편함 해소
  • 개인화된 AI 추천을 통한 사용자 만족도 증대
