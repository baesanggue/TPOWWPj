=== TPO 날씨 추천 시스템 설치 가이드 ===

📋 필요한 파일
- BackendPjTPOWW.war (또는 프로젝트 폴더)
- tpoww_dump.sql
- config.properties (API 키 포함)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ MySQL 데이터베이스 설정

1. MySQL Workbench 실행
2. 메뉴: File → Run SQL Script
3. tpoww_dump.sql 파일 선택
4. 실행 완료 확인

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣ API 키 설정 (3가지 방법 중 선택)

방법 A: config.properties 파일 사용 (권장)
  1. config.properties 파일을 다음 위치에 복사:
     [프로젝트]/src/main/resources/config.properties
  
  2. 파일 내용:
     gemini.api.key=실제_API_키_입력
     weather.api.key=3659dfdc17c8d704ea3b676ae54690c6df40cfa660853eb227dbe7bd57d50747

방법 B: 환경변수 설정
  1. 시스템 환경변수 편집
  2. 새로 만들기:
     변수명: GEMINI_API_KEY
     값: 실제_API_키_입력

방법 C: Eclipse Run Configuration
  1. 프로젝트 우클릭 → Run As → Run Configurations
  2. Apache Tomcat 선택
  3. Environment 탭
  4. Add:
     Name: GEMINI_API_KEY
     Value: 실제_API_키_입력

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3️⃣ 서버 실행

Eclipse 사용 시:
  1. 프로젝트 우클릭 → Run As → Run on Server
  2. Tomcat 10.1 선택
  3. Finish

WAR 파일 사용 시:
  1. BackendPjTPOWW.war를 Tomcat의 webapps 폴더에 복사
  2. Tomcat 시작 (startup.bat 또는 startup.sh)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4️⃣ 접속 확인

로컬 접속:
  http://localhost:8080/BackendPjTPOWW

네트워크 접속 (학생들):
  1. 서버 컴퓨터 IP 확인:
     명령 프롬프트 → ipconfig
     IPv4 주소 확인 (예: 192.168.0.100)
  
  2. 학생 접속 주소:
     http://[서버IP]:8080/BackendPjTPOWW
     예: http://192.168.0.100:8080/BackendPjTPOWW

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5️⃣ 방화벽 설정 (학생 접속 시 필요)

Windows 방화벽:
  1. 제어판 → Windows Defender 방화벽
  2. 고급 설정
  3. 인바운드 규칙 → 새 규칙
  4. 포트 → TCP → 8080
  5. 연결 허용 → 완료

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6️⃣ 테스트

1. 회원가입 테스트
2. 로그인 테스트
3. TPO 추천 테스트
4. 마이페이지 테스트

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❗ 문제 해결

문제: API 키 오류
해결: config.properties 파일 위치 및 내용 확인

문제: DB 연결 실패
해결: MySQL 서버 실행 확인, DB 이름/계정 확인

문제: 학생 접속 안 됨
해결: 방화벽 8080 포트 열기, 같은 네트워크 확인

문제: 404 오류
해결: Clean and Build 후 서버 재시작
