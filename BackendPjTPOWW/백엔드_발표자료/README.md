# TPOWWPj 백엔드 발표 자료

## 📁 파일 목록

이 폴더에는 백엔드 기말 프로젝트 발표를 위한 학습 자료와 발표 자료가 포함되어 있습니다.

### 1. backend_study_guide.md
**용도**: 발표 준비 학습 자료

**주요 내용**:
- 백엔드 아키텍처 패턴 (MVC, 계층화 구조)
- API 연동 기술 (REST API, JSON 파싱)
- 외부 API 연동 실습 (기상청 API 3종, Gemini AI API)
- 세션 관리와 보안
- 데이터베이스 패턴 (DAO, PreparedStatement)
- **예상 질문 및 답변 8개**

**사용 방법**:
- 발표 전 이 파일을 읽고 핵심 개념 숙지
- 예상 질문에 대한 답변 연습
- 코드 예시를 이해하고 설명할 수 있도록 준비

---

### 2. backend_presentation.md
**용도**: 발표 자료 (Markdown 버전)

**주요 내용**:
1. 프로젝트 개요 (목표, 핵심 가치, 기능)
2. 시스템 아키텍처 (3계층 구조, 패키지 구조, DB 설계)
3. 핵심 기능 구현 (날씨 API, 좌표 매핑, AI 추천)
4. 주요 코드 설명 (WeatherServlet, GeminiClient, TpoRecommendServlet)
5. 개발 과정 및 개선 사항
6. 학습 내용 및 성과

**특징**:
- Mermaid 다이어그램 3개 포함
- 핵심 코드 스니펫 15+ 개
- 정량적/정성적 성과 정리

**사용 방법**:
- VS Code 또는 Typora 같은 Markdown 뷰어로 열기
- Mermaid 플러그인 설치하면 다이어그램 확인 가능
- 발표 대본으로 활용

---

### 3. backend_presentation.html
**용도**: 발표 자료 (HTML 버전)

**주요 내용**:
- backend_presentation.md와 동일한 내용
- 현대적인 디자인 적용 (그라데이션, 카드 레이아웃)
- 인쇄 최적화 CSS 포함

**사용 방법**:
1. **브라우저에서 보기**: 파일을 더블 클릭하면 바로 열림
2. **PDF로 저장**: 브라우저에서 Ctrl+P → "PDF로 저장"
3. **발표 시 사용**: 화면 공유로 발표 자료로 사용 가능

**장점**:
- 별도 프로그램 없이 브라우저에서 바로 확인 가능
- 인쇄/PDF 변환 쉬움
- 시각적으로 보기 좋음

## 🆘 문제 해결

### Mermaid 다이어그램이 안 보여요
- **VS Code**: Mermaid Preview 확장 프로그램 설치
- **Chrome**: Mermaid Live Editor (mermaid.live)에서 확인
- **대안**: HTML 버전에는 다이어그램 설명이 텍스트로 되어 있음

### HTML 파일이 이상하게 보여요
- 최신 브라우저(Chrome, Edge, Firefox) 사용
- 파일을 더블 클릭하지 말고 브라우저에서 "파일 열기"로 열어보기

### PDF로 저장 시 색상이 안 나와요
- 인쇄 설정에서 "배경 그래픽" 또는 "Background graphics" 옵션 체크
