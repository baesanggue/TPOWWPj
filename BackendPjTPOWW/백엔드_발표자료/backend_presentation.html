1. 프로젝트 개요

1.1 프로젝트 소개

🎯프로젝트명

TPOWWPj (TPO With Weather)

날씨 정보를 기반으로 사용자 맞춤형 복장을 AI가 추천하는 웹 서비스

핵심 가치

전국 250+ 시군구별 맞춤형 날씨 정보

🤖 AI 기반 추천

Google Gemini를 활용한 지능형 코디 추천

📊 3가지 API 통합

초단기실황, 단기예보, 중기예보 통합

👤 개인화 서비스

선호 브랜드, 색상, 퍼스널 컬러 반영

2. 시스템 아키텍처

2.1 전체 시스템 구조

시스템 아키텍처 다이어그램

클라이언트(JSP) → 프레젠테이션(Servlet) → 비즈니스(Service) → 데이터(DAO) → DB

외부 연동: 기상청 API, Gemini AI API

2.2 3계층 구조

Presentation Layer (프레젠테이션 계층)

  • Servlet: WeatherServlet, TpoRecommendServlet, LoginServlet, MyPageServlet
  • JSP: main.jsp, tpo.jsp, tpoResult.jsp
  • 역할: 사용자 요청 처리 및 응답 생성

Business Layer (비즈니스 계층)

  • Service: TpoService, GeminiClient, LocationCoord
  • 역할: 비즈니스 로직 처리, 외부 API 연동

Data Layer (데이터 계층)

  • DAO: UserDAO, TpoHistoryDAO, UserPrefDAO
  • DTO: UserDTO, TpoHistoryDTO, UserPrefDTO
  • 역할: 데이터베이스 접근 및 데이터 전송

3. 핵심 기능 구현

3.1 날씨 API 연동

🌡️초단기실황조회 (현재 날씨)

목적: 현재 기온, 습도, 강수량, 바람 등 실시간 날씨 정보 제공

발표시각: 매시 40분경 (예: 14:40, 15:40)

제공 데이터: T1H(기온), REH(습도), RN1(강수량), PTY(강수형태)

📅단기예보조회 (3일 이내)

목적: 3일 이내의 시간대별 상세 예보

발표시각: 02, 05, 08, 11, 14, 17, 20, 23시 (하루 8회)

제공 데이터: TMP(기온), SKY(하늘상태), PTY(강수형태), POP(강수확률), WSD(풍속)

🔮중기예보조회 (3~10일 후)

목적: 장기 날씨 예측

발표시각: 06:00, 18:00 (하루 2회)

제공 데이터:

  • 3~7일: 기온 + 날씨 상태 + 강수확률
  • 8~10일: 기온만 제공

3.2 지역 좌표 매핑 시스템

📍LocationCoord 클래스

목적: 전국 시/군/구를 기상청 격자 좌표로 변환

구현: Static HashMap에 250+ 개 좌표 매핑

예시: 서울특별시 강남구 → (61, 126)

// LocationCoord.java
private static final Map<String, Point> coordMap = new HashMap<>();

static {
    add("Seoul", "종로구", "60", "127");
    add("Seoul", "강남구", "61", "126");
    // ... 총 250+ 개 시군구
}

public static Point getCoordinate(String region, String sigungu) {
    return coordMap.getOrDefault(region + "_" + sigungu, 
                                new Point("60", "127"));
}

3.3 AI 코디 추천 시스템

🤖Gemini API 연동

프롬프트 구성 요소:

  1. 기본 정보: 성별, 나이, 날짜, 시간, 활동, 장소
  2. 날씨 정보: 기온, 강수형태, 하늘상태, 강수확률
  3. 선호 정보: 브랜드, 색상, 퍼스널 컬러
  4. 요구사항: 추천 이유 + 항목별 코디 (모자, 상의, 하의 등)

💡AI 응답 파싱

// TpoService.java
String aiText = llmClient.generate(prompt);
String reasonSummary = "";
String aiRecommend = aiText;

// [이유]...[/이유] 태그로 분리
if (aiText.contains("[이유]") && aiText.contains("[/이유]")) {
    int startIdx = aiText.indexOf("[이유]") + 5;
    int endIdx = aiText.indexOf("[/이유]");
    reasonSummary = aiText.substring(startIdx, endIdx).trim();
    aiRecommend = aiText.substring(endIdx + 6).trim();
}

5.2 기술적 도전과제

🔧 문제 1: 기상청 API 발표 시각 처리

문제: 발표 직후 데이터 불안정

해결: 발표 후 10분 버퍼 시간 추가, 새벽 시간 전날 데이터 사용

🔧 문제 2: 중기예보 날짜 매핑 오류

문제: taMin3이 "오늘+3일"인지 "3일째"인지 불명확

해결: API 문서 재확인, targetDay = daysDiff로 직접 매핑

🔧 문제 3: 전국 좌표 데이터 관리

문제: 250+ 개 시군구 좌표 관리 방법

해결: Static HashMap 활용, region_sigungu 복합 키, 기본값 설정
